# ИИ-агент для ретрансляции обращений в поддержку

Концепция ИИ-агента, который собирает обращения техподдержки цифровых продуктов, находит повторяющиеся проблемы и пожелания пользователей и передает их продуктовым командам без дополнительной нагрузки на менеджеров поддержки.

## Идея

- Агент читает звонки (через ASR) и заявки с вложениями (через VL), определяет тип и суть каждого обращения.
- Похожие обращения объединяются в кластеры повторов.
- Раз в неделю продуктовые команды получают дайджест, а при резком росте кластера приходит алерт.
- Срочные обращения маркируются и учитываются в статистике повторов.

## Как устроено

Конвейер из 8 микросервисов на внутренних моделях Qwen (Qwen, Qwen-ASR, Qwen-VL), без внешних API:

`Коннектор → ASR / VL → Предобработка (маскирование ПД) → Анализ (LLM) → Кластеризация → Отчеты и доставка`

Над всем работает оркестратор. Данные хранятся в очереди сообщений, БД результатов и векторном индексе. Агентный режим (выбор инструментов моделью) включается только для спорных случаев кластеризации и сборки дайджеста. Агент только читает исходные тикеты.

Проект концептуальный: кода и работающего прототипа нет. Параметры финансовой модели иллюстративные и заменяются замером на старте внедрения.
